# 签到特效四期：WebGL 空间介质与协议控制台升级（2026-07-11）

## 升级背景

前三期已经完成 Canvas 粒子引擎、48 款独立特效组件以及 NEXUS 统一电影舞台，但实际使用仍有两类瓶颈：

1. **全屏演出的空间介质仍以 CSS 为主**：扫描线、暗角、辉光和色差能够统一风格，但缺少连续流动的星尘、能量潮汐和光谱折射，特效内容与背景之间仍有明显的“前景动画叠在页面上”感。
2. **协议库的信息密度失衡**：48 款特效集中在双列滚动区，用户只能依赖名称和价格盲选；英文代号、事件叙事、演出时长和等级压制没有形成可决策的信息界面。
3. **消费动作过于直接**：旧版点击卡片即扣除甲币并播放，既不利于浏览，也容易误触，无法体现“选择协议 → 校验参数 → 明确启动”的控制台语义。

本期目标不是继续堆叠普通 CSS 光效，而是同时升级渲染底座与交互入口，让全部特效获得可感知的代际提升。

## 本期重大升级

### 1. 全量接入实时 WebGL 空间介质

`RewardEffectOverlay.vue` 新增全屏透明 WebGL Canvas，作为 NEXUS 舞台的程序化空间介质层，覆盖全部 48 款特效。

片元着色器实时合成以下视觉信号：

- 五层 FBM 噪声形成连续流动的星云介质；
- 径向潮汐波随时间、seed 与空间半径传播；
- 环形能量峰与光谱边缘建立纵深参照；
- 稀疏程序化星尘按独立频率闪烁；
- 主色、辅色直接读取 `rewardEffects.ts` 中每款协议的 `accent` 与 `secondary`；
- 信标级、战术级、奇点级和 APEX 使用递增的介质强度与后期饱和度。

WebGL 层位于特效专属背景与内容层之间，因此不会遮挡组件主体和 HUD，又能把背景、粒子和镜头运动连接成同一空间。

### 2. GPU 与兼容性护栏

空间介质采用单个全屏三角形完成绘制，避免传统全屏 quad 的对角线冗余；每帧仅更新分辨率、时间、seed、分级强度和双色参数。

运行时护栏：

- DPR 上限为 `1.5`，防止高分屏填充率失控；
- 禁用深度、模板、抗锯齿和绘制缓冲保留；
- 使用透明画布与 `screen` 混合，不接管原特效组件；
- 特效结束、切换或组件卸载时取消 RAF，并释放 program 与 buffer；
- WebGL 创建、shader 编译或链接失败时静默回退到三期 CSS 舞台；
- `prefers-reduced-motion: reduce` 下不启动 WebGL 动画，沿用全舞台 1ms 降级策略。

### 3. 特效商店升级为 NEXUS 协议控制台

`CheckinRewardCenter.vue` 将原双列卡片墙重构为“协议检查器 + 检索工具栏 + 分级目录”。

新增能力：

- 顶部协议检查器展示等级、APEX 标记、中文名、英文代号、事件叙事、甲币成本、演出时长和压制等级；
- 动态轨道核心根据每款协议的 `tone` 生成专属能量视觉；
- 支持中文名称、英文代号和事件叙事全文检索；
- 支持全部、奇点级、战术级、信标级快速筛选；
- 搜索或切换等级后自动聚焦首条有效协议；
- 分级标题改为 sticky，在长列表滚动时持续保留上下文；
- 卡片补充英文代号、选中态、余额不足态与 APEX 视觉压制；
- 深色主题同步适配检查器、搜索框、筛选器和选中态。

### 4. 消费闭环升级

旧流程：

> 点击卡片 → 立即扣币 → 播放

新流程：

> 浏览/搜索 → 选中协议 → 查看叙事与参数 → 明确点击“启动视觉协议” → 扣币 → 自动收起协议库 → 全屏演出

卡片不再因余额不足而失去浏览能力；用户仍可查看所有高阶协议，仅启动按钮会展示缺少的甲币数量并禁止消费。

```text
  ├─ 钱包与签到状态
  ├─ 协议检查器（本期新增）
  ├─ 搜索与等级筛选（本期新增）
  ├─ 分级协议目录
  └─ 明确启动动作（本期升级）
```

3. **真实浏览器验收**：

## 风险与后续计划

- 当前 WebGL 层是程序化空间介质，并非对底层 DOM 的真实屏幕纹理采样；若后续需要镜头畸变直接扭曲整个应用画面，需要 Electron 层截图纹理或 WebGL 全场景接管。
- 48 个特效组件仍为同步导入，renderer 首包体积未因本期 shader 明显增长，但后续可将奇点级和 APEX 组件改为异步加载。
- 本期已建立统一 GPU 层，下一阶段可把每款协议的爆点时间登记为事件轨道，使 shader 潮汐、镜头 punch 与组件核心爆发逐毫秒同步。

## 小男孩 APEX 专项升级

后续视觉验收发现“小男孩”存在严重表现缺陷：白爆结束后蘑菇云长期不可见，原点精灵投影系数又会在成熟阶段把单粒子放大到上千像素，导致画面在“黑屏”和“整屏色块”之间跳变，无法读出蘑菇云形状。

本次专项修复包括：

- 将蘑菇云点粒子的透视缩放系数从 `300 / depth` 修正为受限的 `42 / depth`，并限制最大点尺寸；
- 把云柱和云冠的全局显影时间从约 1.8 秒压缩到 0.7–0.8 秒，消除白爆后的视觉断层；
- 新增实体体积轮廓：11 段连续云柱、中央扁平云冠、16 组环状翻滚云团及 10 组上翻云冠；
- 对实体几何进行程序化顶点扰动，避免规则球体拼接感；
- 继续保留 shader 点云作为烟尘翻滚、热核和云缘细节层；
- 冲击波按建筑物与爆心距离传播，依次掀翻、推出、压缩并最终抹除 128 个城市实例；
- 地表由暗红热辐射逐步烧蚀为焦黑，城市网格随冲击前沿消失；
- 新增全屏毁灭前沿、焦土热浪和 `TOTAL ANNIHILATION · STRUCTURAL SURVIVAL 0%` 状态确认。

固定关键帧视觉判定结果：

- 修复前：云冠有效像素 `0`，云柱有效像素 `353`，判定失败；
- 修复后：云冠宽 `785px`、云柱宽 `331px`、云柱高 `672px`，云冠宽度为云柱约 `2.37` 倍，蘑菇轮廓判定通过；
- 4.5 秒毁灭阶段中城市背景已被清空，焦黑环境、持续云柱和宽云冠仍保持清晰可读。
