# 签到特效二期：新增 20 款特效设计（2026-07-05）

## 背景

签到奖励中心现有 27 款特效已完成粒子引擎升级（见《签到特效升级设计》）。本期在**不改引擎、零新增依赖**的前提下新增 20 款主题不重复的特效，整体基调：硬核科幻 + 电影级演出，全部走「三幕结构」（蓄势 → 爆发 → 余韵），每次播放由 seed 随机化。

## 设计原则

1. **复用现有架构**：每款特效 = `ParticleCanvas` 场景（`SceneFn` 编排）+ 少量 DOM 结构件（HUD/标签/剪影），叠加 `RewardEffectOverlay` 通用底层。
2. **引擎原语**：`burst`（爆裂）、`streak`（光轨）、`glyph`（字符）、`ring`（冲击环）、`rect`（碎片）、`setTrail`（运动拖尾）、`onFrame`（自定义绘制：光柱/网格/闪电/丝带/圆弧）、粒子 `update`（自定义轨迹：螺旋、引力、正弦）。
3. **seed 随机**：颜色波次、爆点位置、星座连线、裂缝走向等全部走 `api.rng`，同款特效每次演出不同。
4. **性能护栏**：沿用粒子上限 1400 / DPR≤1.75 / 精灵缓存辉光；`onFrame` 自定义绘制避免每帧创建渐变对象（可缓存的预先缓存）。尊重 `prefers-reduced-motion`。
5. **分级定价**：新增最高档「典藏」级（13-14 甲币，6 款），其余为「特级」（10-12 甲币）。`CheckinRewardCenter` 的 `tier` 字段是自由文本，UI 徽章样式自动生效，无需改样式。

## 各特效编排细节

### 1. blackHole 黑洞吞噬（典藏）

- **幕一 蓄势（0-2.2s）**：星野铺场；`onFrame` 绘制倾斜吸积盘（多层旋转椭圆渐变，橙金→炽白）；外围星点被引力拉成弧形 `streak` 螺旋坠入——粒子 `update` 中角速度随半径缩小而暴增（开普勒感）。`setTrail(0.16)` 拉出漩涡拖尾。
- **幕二 视界（2.2-3.4s)**：事件视界收缩，所有光点加速吞入；中心纯黑圆盘（DOM）+ 驻留光子环（细 `ring` 长 maxLife）；画面短暂「静默」半拍。
- **幕三 白洞反弹（3.4s+）**：中心闪爆；上下两束相对论喷流——锥形高速 `streak` 喷射 + 三重冲击 `ring`；余烬 `twinkle` 缓散。
- **DOM**：黑盘中央 "EVENT HORIZON" 微光标签。

### 2. supernova 超新星爆发（典藏）

- **幕一**：恒星呼吸——中心大辉光 dot 尺寸正弦膨胀，表面 `spark` 对流沸腾，`onFrame` 画日珥弧随机腾起。
- **幕二 坍缩（~2s）**：恒星在 300ms 内急缩为白点，全场星尘被瞬间吸入（向心 `update`），静默一拍。
- **幕三 爆发**：300+ 粒全向 `burst` 分三个波次、三段光谱色（金→青→品红），冲击 `ring` 推开星尘；残骸凝成星云——大量低速 `wander` + `twinkle` 尘埃驻留至结尾。

### 3. gravityWave 引力波合并（典藏）

- **幕一**：双中子星互绕——两颗高亮 dot 绕质心旋转（`update` 计算），轨道半径逐圈衰减、转速递增，`setTrail(0.2)` 拖出双螺旋光圈。
- **幕二 合并（~2.6s）**：白闪 + 千新星抛射 `burst`（金红色，重力下坠）。
- **幕三 时空涟漪**：`onFrame` 绘制极坐标网格（同心圆 + 辐射线），径向正弦波从中心传出扭曲网格线；全场星点按「距离-时间」相位同步抖动，涟漪三波渐弱。

### 4. riftTear 时空裂隙（典藏）

- **幕一 应力**：画面细微抖动（DOM filter/transform 摆动）；`onFrame` 画蔓延的细光缝折线（seed 决定走向），伴随低鸣感的暗紫微粒聚集。
- **幕二 撕裂（~1.8s）**：锯齿裂缝轰然张开——`onFrame` 多段折线双描边（外紫内白），缝内异次元渐变发光；异界符文 `glyph`（ᚠᚱᛟ 等卢恩字符）与碎片 `rect` 被吸出悬浮，缝缘 `spark` 持续迸溅。
- **幕三 缝合**：一点光沿缝缘扫过将裂缝拉合（折线长度回退），空间回弹 `ring` 波纹，残留符文淡出。

### 5. aiAwaken AI 觉醒之眼（典藏）

- **幕一**：黑暗中四周代码流 `glyph` 向心汇入，速度渐快，`setTrail(0.3)`。
- **幕二 睁眼（~1.8s）**：`onFrame` 绘制巨大虹膜——多层同心圆弧段 + 辐射状纹理（seed 生成扇段分布）反向旋转；虹膜纹路通电逐段点亮，瞳孔收缩定焦一次。
- **幕三 注视**：瞳孔中浮现签到数据 `glyph`（日期、连签天数、+甲币数字环绕旋转）；结尾眨眼（上下暗幕合拢）熄灭，只余一点余光。
- **DOM**：底部 "CONSCIOUSNESS ONLINE" 打字机字幕。

### 6. dysonRing 戴森星环（典藏）

- **幕一**：中央恒星燃烧——大辉光 dot + 表面对流 `spark`；星野缓漂。
- **幕二 建造**：`onFrame` 沿透视椭圆轨道逐段绘制发光构件（近大远小、近亮远暗做伪 3D），构件按 seed 次序点亮；施工无人机（小 dot 拖尾）在恒星与环带间穿梭。
- **幕三 合拢供能**：全环合拢瞬间泛白，向屏幕两侧输出能量光束扫过；"MEGASTRUCTURE ONLINE" HUD 浮出。

### 7. collider 粒子对撞机（特级）

- **幕一**：`onFrame` 画大型环形加速器轨道（双圈 + 四段加速腔高亮）；两束粒子团（`streak` 簇）反向加速，逐圈提速增亮。
- **幕二 对撞（~2.4s）**：顶点白闪；喷注爆发——数条锥形 `spark`/`streak` 喷流；衰变轨迹用带磁场偏转的 `update`（速度垂直方向加速度）画出螺旋径迹，重现云室质感。
- **幕三 发现**：粒子符号 `glyph`（μ π γ ν Ψ）发光漂浮，DOM 徽章 "NEW PARTICLE DISCOVERED"，能级坐标弧线余韵。

### 8. mechaBoot 机甲启动（特级）

- **幕一**：黑场，DOM 终端逐行自检（`REACTOR……OK / SERVO……OK / NEURAL LINK……SYNC`），伴随少量 `glyph` 字符碎屑坠落。
- **幕二 点睛（~2.2s）**：两道横向光缝（`onFrame` 光带自中线向两侧展开）如同目镜点亮；机体蒸汽——大尺寸低透明度 dot 缓慢上浮。
- **幕三 全系统上线**：HUD 环序列展开（`ring` 递次 + `onFrame` 刻度弧线），边缘电流 `spark` 迸溅，结尾 power-surge 全屏微闪 + "ALL SYSTEMS NOMINAL"。

### 9. orbitalStrike 天基动能打击（特级）

- **幕一 锁定**：DOM 十字准星从大到小旋转收拢锁定屏幕中心，四角警示条闪烁 "TARGET LOCKED"；顶部天区扫描线。
- **幕二 光柱（~1.6s）**：`onFrame` 自屏顶至中心绘制炽白光柱（宽度脉冲 + 边缘青色电离光），落点白闪。
- **幕三 冲击**：半圆向上 `burst` 溅射火花（带重力回落）、三道扩散 `ring`、缓升烟尘 dot;地表裂纹（`onFrame` 短折线）发红渐熄。

### 10. galaxyMap 全息星图（特级）

- **幕一**：数百星点从底部升起入场，按深度分层（远小暗慢、近大亮快）形成伪 3D 视差；全体绕屏幕中心缓旋（`update`）。
- **幕二 连线**：`onFrame` 依 seed 选取星点绘制发光星座连线（逐段生长动画），旁侧 `glyph` 标注星名代号。
- **幕三 锁定**：随机一颗星放大脉冲 + 三重 `ring` 锁定框，弹出坐标文字；结尾星图整体上收淡出。

### 11. solarFlare 日冕风暴（特级）

- **幕一**：屏幕左下巨日边缘（`onFrame` 大圆弧 + 大气辉光），日面 `spark` 颗粒对流沸腾。
- **幕二 喷发（~2s）**：磁力线弧（`onFrame` 贝塞尔弧）逐条亮起并拉出等离子体环，断裂瞬间 CME 抛射——大团橙白 `spark`/`streak` 冲向对角。
- **幕三 抵达**：粒子风掠过全屏（横向流场），屏幕右上泛起极光帘丝带；HUD "SOLAR STORM · CLASS X"。

### 12. nanoSwarm 纳米蜂群（特级）

- **幕一**：四周涌入数百绿金微粒（小 dot、高 `wander`），虫群般游弋。
- **幕二 聚形（~1.8s）**：粒子受目标采样点引力收敛（实现：离屏 canvas 绘制 "已签到 ✓" 文字后 `getImageData` 采样为目标点集，粒子 `update` 弹簧吸附），拼出发光文字并呼吸抖动。
- **幕三 解散**：集体炸散为 `streak` 四散逃逸，残留少量萤光 `twinkle`。

### 13. holoDisassemble 全息拆解（特级）

- **幕一**：中心全息件（DOM 线框立方/甲币徽章）通电成型，环绕检修弧线旋转。
- **幕二 拆解**：DOM 多层部件分离位移 + 旋转悬浮，每层剥离时迸出 `rect` 碎屑；`onFrame` 画引出标注线 + `glyph` 部件编号。
- **幕三 重组**：部件回吸合体，合体瞬间 `ring` + 纵向光柱，"UPGRADED v+1" 浮出。

### 14. rocketLaunch 曙光发射（特级）

- **幕一 倒计时**：巨型 `glyph` 数字 3→2→1（每个带缩放冲击 + `ring`），发射塔简约剪影（DOM），塔顶警示灯闪。
- **幕二 点火（~2.2s）**：底部烈焰喷流——高密度橙白 `spark` 下喷反溅 + 大粒径浓烟横滚，DOM 全屏低幅震动。
- **幕三 升空**：火箭光点拖长尾焰加速冲出屏顶（`setTrail` 拉尾），抛离级段 `rect` 翻滚坠落；尾迹凝成贯穿光柱，"LIFTOFF" 定格。

### 15. bioScan 生体扫描（特级）

- **幕一**：横向扫描光带自上而下（`onFrame` 渐变带），路径迸出网格化 `spark`。
- **幕二 双螺旋**：两串 dot 按正弦相位对旋上升（`update` 螺旋轨迹），碱基横杠用短 `streak` 连接，随机碱基高亮闪烁。
- **幕三 认证**：螺旋收束成一道纵向光柱，绽放绿色确认 `ring`，`glyph` "IDENTITY VERIFIED ✓"。

### 16. empBlast 电磁脉冲（特级）

- **幕一 充能**：中心核球电弧——`onFrame` 每帧重掷随机折线闪电（seed 抖动）噼啪缠绕，电荷 `spark` 聚集。
- **幕二 脉冲（~1.8s）**：一圈畸变 `ring` 高速扩散，波前掠过处炸出 `glyph` 乱码碎屑与 `spark` 雨；DOM 层同步 glitch（clip-path 切片抖动 + RGB 错位阴影）。
- **幕三 瘫痪余韵**：四角残余电弧偶发闪跳，字符雨熄灭坠落，最后一次微弱复电闪烁。

### 17. satelliteSweep 卫星过境（特级）

- **幕一**：屏底地球弧线 + 大气层辉光（`onFrame`），星野缓漂。
- **幕二 过境**：卫星（DOM 小构件，展开太阳翼动画）沿抛物线划过，尾迹 `streak`；向地面投射三角通讯波束（`onFrame` 渐变扇形），数据 `glyph` 沿波束下行。
- **幕三 链路**：地面站 `ring` 应答上行，"UPLINK 100% · SYNCED" HUD；卫星驶出画面留轨迹余光。

### 18. energyShield 相位护盾（特级）

- **幕一 展开**：`onFrame` 绘制六边形蜂窝盾面（伪球面透视：中心大、边缘压扁），六边形自中心逐圈点亮铺满。
- **幕二 承击**：2-3 发来袭 `streak` 弹头命中盾面（seed 定落点），命中点六边形高亮、邻接格延迟点亮形成涟漪传播，火花 `burst` 溅射。
- **幕三 稳定**：盾面流光巡回一周，"SHIELD INTEGRITY 100%"，呼吸微光淡出。

### 19. deepSonar 深海声呐（特级）

- **幕一 下潜**：全场深青暗场，气泡 dot 上浮，探照灯锥形光（`onFrame`）左右缓摆。
- **幕二 扫描**：中心声呐扫描臂旋转（`onFrame` 扇形余辉渐变），扫过处点亮成群生物光点（`twinkle`），同心 `ring` 脉冲外扩、遇「目标」回波增亮。
- **幕三 接触**：巨型鲸形暗影（`onFrame` 贝塞尔剪影 + 轮廓发光点）横越屏幕，尾流粒子翻涌，"CONTACT CONFIRMED"。

### 20. skyUplink 云端上载（特级）

- **幕一**：底部数据池——`glyph` 0/1 字符翻涌沸腾。
- **幕二 上载**：多条垂直数据束（`streak` 上行 + 随行 `glyph`）冲向顶部云核；DOM 云图标 + `onFrame` 环形进度弧随时间充能，束流命中时进度跳动。
- **幕三 完成**：进度 100% 瞬间云核爆出确认 `ring`，金色光雨回洒全屏，"SYNC COMPLETE"。

## 验证

- `npm run typecheck` + `npm run build`（项目无测试框架）。
- `npm run dev` 手动抽查：每款至少播放 2 次（不同 seed）确认演出随机化；检查粒子峰值不超上限、无明显掉帧；开启系统「减少动态效果」验证 reduced-motion 降级。
