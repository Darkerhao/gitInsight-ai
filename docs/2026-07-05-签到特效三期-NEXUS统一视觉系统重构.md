# 签到特效三期：NEXUS 统一视觉系统重构（2026-07-05）

## 背景

一期完成粒子引擎升级（27 款）、二期新增 20 款硬核科幻特效后，特效**内容层**已经足够强，但**系统层**缺失：

1. **无体系感**：`effectOptions` 是散在 `CheckinRewardCenter` 里的平铺数据（label/cost/icon/tone），47 款特效各自为战，像"独立小动画列表"。
2. **屏幕语言硬编码**：`RewardEffectOverlay` 用 ~400 行逐特效 CSS 类堆配色与背景，新增特效要在 4 处登记，且没有统一的镜头、后期处理与开闭幕仪式。
3. **分级不压制**：`tier` 是自由文本徽章，低/中/高档特效在商店与播放时的视觉权重几乎无差别，用户感知不到"贵"。
4. **无叙事闭环**：点击 → 播放 → 结束，没有"消耗甲币 = 能量注入 → 空间展开 → 事件发生 → 世界恢复"的事件级体验。

## 目标（本期范围）

- 建立统一世界观与视觉语言，47 款特效同属一个系统。
- 按 cost 重建三级视觉压制，商店与舞台双端可感知。
- 每款特效具备四段式动效协议（entry / loop / exit / camera）。
- 点击消费成为事件级体验（能量注入 → 协议执行 → 系统恢复）。
- 命名升级为"未来科技产品功能"气质（中文产品名 + 英文协议代号）。
- **零改动 47 个特效组件**；每款总时长逐 ms 不变（组件内有绝对时间点与 CSS 时长硬编码）。

## 世界观：NEXUS 深空中枢

GitInsight 的 AI 中枢是一座深空指挥舰桥（NEXUS）。用户是持有甲币能量配额的指挥官；每个特效是一次由能量授权执行的**视觉协议（Visual Protocol）**：

> 注入甲币 → 舰桥让位（世界暗场、光圈展开、能量束汇入）→ 协议执行（特效三幕演出 + 分级镜头语言）→ 协议完成（PROTOCOL COMPLETE，能量环收束，世界恢复）。

视觉基调 = **赛博 HUD × 宇宙能量场** 混合：深空石板底（#020617 系）、等宽字体协议 HUD、青紫金三系强调色、加法混色辉光、扫描线/噪点/暗角/色差的胶片式后期。

## 架构：数据驱动的电影舞台

```
rewardEffects.ts（唯一契约）
  ├─ EFFECT_TIERS         三级压制元数据
  ├─ EFFECT_OPTIONS[47]   label/codename/narrative/cost/tier/apex/icon/tone
  │                       accent/secondary/backdrop（舞台配色与氛围幕入数据）
  │                       camera/shake（镜头预设 + 震屏强度）
  │                       phases{entry,loop,exit}（四段时长，和 = 原总时长）
  │                       motion{entry,loop,exit,camera}（动效说明）
  ├─ EFFECT_DURATIONS     由 phases 求和派生（数值与二期完全一致）
  └─ groupEffectsByTier() 商店分组

RewardEffectOverlay.vue（统一电影舞台，读数据渲染）
  层序：backdrop(-4) < camera rig[bloom+冲击波+内容](1) < 能量注入束(3)
        < grain(4) < scanlines(5) < chroma(5) < vignette(6) < 回收环(6)
        < cinebar(7) < 协议HUD(8) < flash(9)
  · 相机 rig 只作用于内容层；后期层固定屏幕空间（正确的电影分层）
  · 全部动画时长由 --fx-ms/--fx-entry-ms/--fx-exit-ms CSS 变量驱动
  · 逐特效 CSS 类全部删除，配色/背景来自数据内联

CheckinRewardCenter.vue（协议库商店）
  · 按 奇点→战术→信标 分组渲染，组内按甲币降序
  · 分级卡片压制 + APEX 徽记 + 能量注入充能反馈 + 甲币脉冲
```

## 四段式动效协议

每款特效 `phases = {entry, loop, exit}`，三段之和恒等于原总时长（组件零改动的前提）：

- **ENTRY 进入**：白闪 + 冲击波光圈展开；战术级以上能量束自屏幕边缘汇入中心（"甲币能量注入"）；HUD 打字上线；奇点级黑边合拢入画。
- **LOOP 持续**：特效组件自身的三幕演出（蓄势→爆发→余韵，二期已建立）；舞台侧持续辉光呼吸、扫描线推移、分级镜头运动。
- **EXIT 退出**：一道向心收束的"世界回收环"（`--fx-exit-delay` 精确对齐）；HUD 切换 `PROTOCOL COMPLETE · SYSTEM RESTORED`；黑边退场、暗角回收、镜头归位。
- **CAMERA 镜头**：九种预设之一，独立于内容层运行（见下表）。

## 每特效四段动效说明

完整的 entry / loop / exit / camera 说明已作为结构化数据登记在
[rewardEffects.ts](../src/renderer/src/components/rewards/rewardEffects.ts) 每个条目的 `motion` 字段
（同时用于商店 tooltip），此处按分级摘录代表性条目，其余同构：

**奇点坍缩 SINGULARITY COLLAPSE（14 ⬢，phases 700/4300/1000）**
- entry：星野铺场，倾斜吸积盘多层旋转显影；舞台八向能量束汇入 + 黑边合拢。
- loop：星光被引力拉成螺旋坠入（角速度随半径暴增）→ 2.2s 视界收缩、光子环驻留、静默半拍 → 3.6s 白洞闪爆 + 上下相对论喷流 + 三重冲击环。
- exit：余烬缓散，EVENT HORIZON 熄灭归黑；世界回收环收束，PROTOCOL COMPLETE。
- camera：组件自带（吸入推近→静默收缩→反弹回冲），舞台不叠加；色差撕裂与重暗角全程生效。

**天基打击 KINETIC LANCE（12 ⬢，phases 700/3700/800）**
- entry：十字准星旋转收拢锁定，四角警示条闪烁 TARGET LOCKED。
- loop：1.6s 炽白光柱自屏顶贯落（宽度脉冲 + 青色电离缘），落点白闪 → 半圆火花溅射 + 三道冲击环 + 烟尘缓升。
- exit：地表裂纹发红渐熄，警示解除，回收环收束。
- camera：punch —— 光柱贯落瞬间猛烈急推 + 2 档震屏。

**轨道座舱 ORBITAL COCKPIT（10 ⬢，phases 600/3800/800）**
- entry：座舱边框 + 刻度罗盘通电，四块遥测面板依次上线；四向能量束注入。
- loop：雷达扫掠臂旋转拖出余辉扇面，目标环收缩锁定 + 十字闪光，舷侧遥测光条上行。
- exit：面板逐一下线，罗盘断电收拢。
- camera：dolly —— 驾驶位推镜落定，中段随罗盘缓旋微漂，结尾回拉。

**极光天幕 AURORA VEIL（6 ⬢，phases 700/3600/900）**
- entry：星野渐显，光帘自地平线缓缓升起（无 HUD，纯氛围开场）。
- loop：三层色相流动的极光丝带正弦摆动，极光尘上浮，流星偶发划落。
- exit：光帘垂落收拢，星野最后闪烁熄灭。
- camera：drift —— 极缓漂移仰视，不打扰氛围。

## 交互体验：事件级闭环

1. **点击 = 能量注入**：卡片进入 `is-charging`（高亮描边 + 扫光 + 图标充能脉冲 0.72s），甲币数字 `coin-pop` 脉冲，与舞台 entry 并行不阻塞。
2. **空间展开**：舞台白闪 + 光圈冲击波，战术级以上能量束自屏幕边缘汇入中心 —— 消耗的甲币"流进"特效。
3. **环境被影响**：全屏 backdrop 暗场接管应用，奇点级附加 `backdrop-filter: blur` 使界面"熔化"退后，黑边入画。
4. **世界恢复**：exit 阶段向心回收环 + `PROTOCOL COMPLETE · SYSTEM RESTORED`，随后整层卸载，应用界面原样归还。

## 技术实现方案

**本期落地（零新增依赖）**：Canvas 2D 粒子引擎（一期，负责内容层：加法混色、拖尾、seed 随机、三幕编排）＋ **数据驱动 CSS 舞台**（本期，负责屏幕语言：相机 rig 变换、扫描线/噪点/暗角/色差近似/黑边/HUD，全部 GPU 合成友好的 transform/opacity 动画，`--fx-*` 变量驱动时长与分级系数）。性能护栏沿用：粒子 ≤1400、DPR ≤1.75、辉光精灵缓存、`prefers-reduced-motion` 全舞台 1ms 降级。

**下一期候选（按收益排序）**：
1. **WebGL 后处理管线**（pixi.js 或裸 WebGL 单 quad shader）：把 grain/chromatic aberration/bloom/lens distortion 升级为真实屏幕空间 shader（当前为 CSS 近似），一个 `<canvas>` 叠加层即可接管全部后期，特效组件仍零改动。
2. **GSAP timeline**：若需要把 entry/loop/exit 与组件内部时间点做逐毫秒编排（如镜头 punch 精确对齐对撞瞬间），用 GSAP 替换 % 关键帧；代价是新增依赖。
3. **Three.js / R3F**：仅当需要真 3D（体积光、星球、景深）时引入；建议只为 APEX 档 6 款做 3D 版本，`effectComponentMap` 按档位懒加载，避免包体积影响全量。
