# 签到特效五期 · 创世级协议与 48 款全量重写

日期：2026-07-26

## 概述

五期在 NEXUS 统一视觉协议系统（三期契约 + 四期 WebGL 空间介质）之上做两件事：

1. **新增最高等级「创世级 GENESIS」**：15 款 666 甲币的禁忌级演出，位于 信标 → 战术 → 奇点 之上（grade 4），按次消费。
2. **逐款重写全部 48 款现有特效的视觉编排**：契约（注册数据、时长、根类名、seed、配色）不变，场景编排全部推向「高端大气、科技感十足」——更细的节拍踩点、更强的纵深层次、更丰富的次级系统、更克制高级的配色。

完成后协议库共 **63 款**。

## 契约与舞台改动

- `rewardEffects.ts`：`EffectTierKey` 增加 `'genesis'`；`EffectTierMeta.grade` 扩为 `1|2|3|4`；`EFFECT_TIERS.genesis`（costRange [666,666]）；15 个注册项（apex 全员）；`groupEffectsByTier` 顺序改为 创世 → 奇点 → 战术 → 信标。
- `RewardEffectOverlay.vue`：15 个组件接入 `effectComponentMap`；`fx-tier-genesis` 完整舞台档位（第三道冲击波、八向能量注入、色差、电影黑边、HUD 偏移全部对齐奇点级并加强）；创世级专属：双反向鎏金法阵环 + 呼吸圣辉（`fx-genesis-rig`）、熔金流光协议名、金辉 HUD 括角；空间介质强度随 grade 4 提升。
- `CheckinRewardCenter.vue`：等级筛选 4 列 → 5 列；创世级商店视觉（鎏金流光组头、金红渐变描边卡片 + 巡回光泽、检视台金框强化，深浅色主题各一套）。

## 重写原则（48 款）

概念身份与注册契约不变；编排全部重构：`api.at` 精确踩点、近大远小/远景压暗/视差纵深、次级系统（余尘/回波/二次噼啪/HUD 确认微文案）、白热核心 + 主色辉光 + 辅色点缀的克制配色、DOM 徽章统一「等宽英文微文案 + 中文主标」双层排版。特例：LittleBoy 的 three.js Explosion 子系统未动，只升级 DOM/CSS 叠加层；BlackHole 与 SpaceJump 保留 `camera:'none'` 自带镜头架构。
