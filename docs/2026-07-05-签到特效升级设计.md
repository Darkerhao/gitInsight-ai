# 签到奖励特效升级设计（2026-07-05）

## 背景与问题

签到奖励中心（`src/renderer/src/components/rewards/`）现有 27 个特效，全部为纯 CSS 动画，观感"平平无奇"，根源：

1. **布局是死的**：粒子位置由 `(index * 13) % 78` 之类取模伪随机生成，排布规律感强；`seed` 已传入 `RewardEffectOverlay` 但特效组件未消费，每次播放完全一样。
2. **粒子密度与物理感不足**：CSS 无法做运动拖尾、加法混色（additive blending）、重力/阻力物理，光效"糊"不起来。
3. **节奏平**：几乎所有特效都是"淡入→停留→淡出"单一节拍，缺少爆发、波次、余韵。

## 目标

- 27 个特效全部升级，特级（特级 tier）与普通级拉开可感知的差距，与甲币定价匹配。
- 每次播放基于 seed 随机化，观感不重复。
- 零新增依赖；Electron 桌面端 60fps；尊重 `prefers-reduced-motion`。

## 方案（已确认）

**共享 Canvas 2D 粒子引擎 + 保留 CSS 结构层**：

- 新增 `rewards/engine/particleEngine.ts`：
  - `createRng(seed)`：mulberry32 种子随机。
  - 粒子系统：位置/速度/加速度（重力）、阻力（`drag^dt`）、湍流漂移、生命周期透明度包络（fadeIn/fadeOut/twinkle）、尺寸插值。
  - 渲染形状：`dot`（辉光光点，预渲染 radial-gradient 精灵缓存）、`spark`、`streak`（沿速度方向拉伸的光条）、`glyph`（文字字符）、`ring`（扩散环）、`rect`（纸屑，带 3D 翻转抖动）。
  - 加法混色 `globalCompositeOperation: 'lighter'`；**运动拖尾**通过每帧 `destination-out` 半透明擦除实现。
  - 时间线编排：`at(ms, fn)`、`every(ms, fn)`、`onFrame(fn)`（自定义绘制：极光丝带、透视网格、闪电弧等）。
  - 性能护栏：粒子上限 ~1200，DPR 上限 1.75，辉光用精灵缓存而非 shadowBlur。
- 新增 `rewards/engine/ParticleCanvas.vue`：接收 `seed/duration/scene`，挂载全屏 canvas，负责 rAF 循环生命周期与 reduced-motion 跳过。
- `RewardEffectOverlay.vue` 把 `seed` 传给激活的特效组件。
- 27 个特效组件逐个重写：`<ParticleCanvas :scene="scene" />` 承担粒子层，原有 DOM 结构件（控制台/HUD/签名标签）保留并打磨；每个特效的 scene 用引擎原语编排独有的多波次演出。

### 备选方案（未采纳）

- 纯 CSS 深度打磨：工作量小但天花板低，做不了拖尾与物理。
- 引入 tsparticles/canvas-confetti：增加依赖体积且 27 个特效易趋同。

## 特效编排要点（示例）

- 臻彩烟花：多波次火箭升空（拖尾）→ 爆裂 150-260 颗重力火花 + 二次爆裂余烬闪烁。
- 极光天幕：onFrame 绘制正弦摆动的多层极光丝带 + 星野漂移。
- 代码矩阵：canvas 真字符雨（亮头 + 渐隐尾迹），保留控制台 DOM。
- 星际跃迁/空间跃迁:中心加速外扩的星光 streak 隧道。
- 数据风暴：字符涡旋 + 闪电弧。

`npm run typecheck` + `npm run build`（项目无测试框架）；手动 `npm run dev` 播放抽查。
