# 一周日报保存失败

## 现象

- 在“一周日报”页面编辑已生成的日报后，点击“保存当前日报”提示“保存日报失败，请稍后重试”。
- 单独提交飞书会先保存脏草稿，因此保存失败后同一条日报无法继续提交飞书。

## 复现步骤

1. 进入“一周日报”，选择日期和项目并生成日报。
2. 编辑任意已生成日报正文。
3. 点击“保存当前日报”或“单独提交飞书”。

## 期望与实际

- 期望：编辑后的日报保存成功，并可继续提交飞书。
- 实际：保存阶段失败，飞书提交被阻断。

## 环境

- Windows 11
- GitInsight AI Standard 3.8.0
- Electron 37 / Vue 3

## 最小复现信号

将 Vue 响应式日报结果直接执行 Electron IPC 同类的结构化克隆：

```text
DataCloneError: #<Object> could not be cloned.
```
