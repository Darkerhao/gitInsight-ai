## 验收标准
- 支持日期范围和项目筛选，从时间长河记录生成活跃日期、日报累计提交/文件、涉及项目、里程碑及技术标签。
- 3 种卡面：时光纸笺 50 万、工程蓝图 100 万、星轨纪念 200 万。
- 免费预览，购买后永久解锁；重复购买不重复扣币，保存失败整体回滚，账本自动记录。
- 支持 SVG 与 PNG 导出，预览与导出复用同一生成器；无记录、非法日期、加载失败或未解锁时禁止导出。
- 既有主题、花园、账本行为不变；卡面不能作为主题或花盆装备。

## 取舍与边界
- SVG 为原始矢量卡面，PNG 通过浏览器原生 Canvas 将同一 SVG 以两倍分辨率导出为 2400 × 1640 图片，无新增依赖。导出失败提示并允许重试，处理中禁止重复导出。
- 项目按日报归属精确匹配。合篇日报不拆分统计；提交和文件为日报累计值，非去重值。里程碑沿用时间长河标记，卡片注明口径。
- 卡面解锁持久化，筛选和预览为临时 UI 状态；导出文件为可保存成果，不新增卡片历史表。
