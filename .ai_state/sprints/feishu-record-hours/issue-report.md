# 飞书日报发布反复提示无法读取提交记录

- 2026-10-18，当前工作区 v3.8.14；单模块 Bugfix，置信度 0.99。保留 report-performance 在途状态与改动。
- 复现：登录飞书、发布日报，提示“无法读取飞书提交记录”；当前可见飞书窗口实际已显示“我的提交记录”及历史日报。
- 根因证据：真实记录页字段为“每日工作时长（h）”，值为 `8.0`。`feishuAuth.ts` 的字段和工时识别正则要求字段名后直接出现冒号或数字，不接受单位括号，所有记录均被排除。
- 期望：能读取带单位的工时字段，无重复时直接发布；有重复或读取失败时仍要求确认，自动任务停止；读取失败应说明原因。
- 回归：在 `tests/publicationGuard.test.mjs` 使用真实字段格式执行实际注入脚本，覆盖 8 小时匹配、非目标日期/工时排除及确认流程。
