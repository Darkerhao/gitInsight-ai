# Desktop reliability — 2026-10-08

## Scope
用户要求直接完成上一轮提出的七项完善。复用当前干净 checkout；互斥写集实施，不提交、不发布、不操作用户真实飞书数据或覆盖用户数据。路径 Refactor，置信度 0.98。

## Implementation
1. 应用入口单实例锁，第二实例只唤醒现有窗口。启动错误明确显示，禁止损坏配置静默重置。
2. 配置/密钥文件采用串行保存、临时文件原子替换，读取仅 ENOENT 返回初始值。并发读取不得看见半次保存；写失败保留可用旧文件。复用一个文件原子写入工具。
3. renderer 中任务编辑配置和运行快照分工明确。后台通知只合并 last* 状态字段，不替换可编辑字段、不复活已删除任务；主进程保存用户配置保留最新运行状态。
4. 飞书查重收敛到主进程统一提交入口，手动入口允许明确确认后继续，自动入口遇重复/不可确认停止并显示待核对。消除单日页面专属查重实现。查重策略不依赖 Vue；既有提交成功但本地日志失败语义保留。所有入口复用同一规则，避免无上限重试。
5. 本地配置/仓库/历史先可用，飞书元数据后台加载，不为后台读取再次保存配置；初始化异常明确反馈。已有配置修改提示不丢失。
6. 设置页增加主动备份/恢复：单一版本化本地备份格式，包含 SQLite 全量数据和非敏感配置，密钥/Cookie 不进入可迁移备份，UI 明确需重新配置。限制文件大小、校验格式/SQLite 完整性和必需表后再安排恢复。恢复前确认并备份当前数据，重启时在 DB/任务初始化前应用，成功后才删除 pending；恢复后关闭自动同步，避免换机误提交。无效备份不得触碰当前数据。凭证加密机制保持 safeStorage，无新依赖。
7. 删除无调用入口的农场业务代码/类型及新建农场表逻辑，但不 DROP 用户历史表或数据。打包只保留 electron-builder.config.cjs，同步测试/文档。删除确认无调用的直接依赖。

## Acceptance Criteria
- AC1: 单实例回归测试证明第二进程不注册 IPC、不初始化数据库/调度；现有窗口最小化后可唤醒。
- AC2: 文件/配置测试覆盖首次运行、无效 JSON、密钥解密失败、部分写入失败、并发读写；旧配置不丢失，错误可见。
- AC3: 任务编辑测试覆盖运行通知到达时保留名称/时间/启用/删除等未保存编辑；保存不回退后台运行状态。
- AC4: 发布测试覆盖单日/批量/自动的无重复、重复、检查不可用、明确确认、取消；未授权覆盖不 POST；远端成功本地失败仍保留成功。
- AC5: 初始化测试在飞书请求悬挂/失败时本地数据加载仍能完成；后台读取不写配置，不覆盖用户编辑。
- AC6: 备份恢复测试覆盖导出无凭证、真实 SQLite 往返、非法/超限/损坏/缺表备份拒绝、恢复前快照、重启恢复和自动同步关闭。
- AC7: 农场及旧打包配置无执行引用，历史 SQLite 数据不删除；release artifacts 契约测试通过。
- AC8: npm test、npm run typecheck、npm run build、git diff --check 通过；浏览器回归及隔离 Electron 实跑记录准确结果，真实远端提交不执行。
