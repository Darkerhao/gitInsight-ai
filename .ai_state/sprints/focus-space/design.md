# 专注空间

## Round 1
复用商品目录、purchaseCoinItem、永久资产表和账本。新增 scene 类型：免费简洁书桌，雨夜100万、咖啡馆200万、宇宙舱300万。静态 CSS/SVG 场景，无资源依赖。
应用层单一计时状态；运行时保存截止时间，暂停保存剩余时长；专注25分钟/休息5分钟，完成后用户主动开启下一阶段，结束不触发完成提醒。页面卸载不停止计时；通知在 App 层监听，音效可关闭。只承诺应用打开期间跨页面连续，关闭应用后不运行计时。
先选场景预览再购买，未解锁场景不可用于正式专注；预览与实际使用分离。免费场景不依赖付款。
范围排除音乐库、排行、发币和花园联动。保留既有未提交修改。

## 验收标准
- 免费书桌可开始、暂停、继续、结束25分钟专注；完成后可开启5分钟休息。
- 跨页面返回剩余时间正确，挂起恢复不会漂移，完成仅通知一次，结束不会通知。
- 三个付费场景价格正确，先预览后购买，余额不足禁购，取消/失败不扣款；购买永久解锁且账本仅一笔。
- 应用内跨页完成提示及可关闭提示音。

## Done Contract

- npm run typecheck、npm run build 通过；保存界面截图并检查。
- 独立代码/规格审查与收敛检查完成；不提交或推送。

## 场景视觉与动画迭代（2026-10-28）
用户认为付费场景缺乏购买吸引力，并要求增加动画。改为三幅独立本地 SVG：城市雨夜落地窗、暖光咖啡馆、环形宇宙观景舱；大画幅、左侧留白计时、完整缩略图，删除原共用付费桌窗绘制。
雨丝下落/热气升腾、灯光呼吸/浮尘、行星云带缓转/星光/流星使用 SVG CSS 动画。主场景内联可信本地 SVG，渐变 ID 和样式按场景隔离；缩略图保持静态。系统减少动态效果停止主场景动画，切换淡入也禁用。无新依赖、请求、购买或计时逻辑改动。
