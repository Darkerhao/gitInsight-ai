# 前端动效边界

动效使用现有 Vue、CSS 和浏览器 API，无新增运行时依赖。`useCardTilt` 是日报纸张和纪念卡唯一指针倾斜实现；命中区域固定，只有内部图像变换。媒体偏好、失焦、取消和卸载清理指针帧与 CSS 变量。

纪念卡预览外层承载高光与倾斜；导出继续读取 `renderWorkMemoryCard` 原始 SVG，因此导出数据与权限不依赖视觉状态。购买短反馈在工坊购买返回成功后消费结果，不创建钱包或资产状态。

生成和发布的细边光线由原草稿/请求状态派生；成功、失败、取消停止等待光效。文字立即可读可操作。页面仍 80ms 淡入、立即离场；图表/Three.js 仍保持懒加载边界。

`useMessages` 只保留本次更新中单条新 ID 的入场资格，并在渲染后清除；筛选和批量刷新不重播。消息中心和工作台使用相同原生短淡入，Vue 过渡钩子立即完成，不延长列表或导航生命周期。

App 将文档可见性映射为 `data-motion-paused`，专注画面另用 IntersectionObserver 判断是否滚出视口，均只停止装饰。专注剩余时长仍由原截止时间模型计算；系统减少动态效果实时作用于倾斜、图表和 CSS 反馈。

颜色、尺寸与动画时长统一使用现有主题变量；SVG 图片与已有动画演出继续各自保持单一来源。
