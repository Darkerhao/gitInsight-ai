# Route note — 2026-07-25 UI refresh

## 证据

- 当前应用是 Electron + Vue 3 + Element Plus，Lucide 已在依赖中。
- 工作树干净；既有日报生成主流程、状态检查、编辑、保存与发布逻辑已存在。
- 现有视觉令牌偏通用后台：浅灰页面、规则网格、默认 Element Plus 组件；与用户要求的沉浸式艺术画布有明显差距。
- codebase-memory MCP 在当前会话不可用；已按仓库约定回退到定点源码阅读与命令验证。

## 候选路径

1. 只改全局颜色：风险低，但无法改善层级、动效和页面叙事。
2. 重写数据/页面架构：视觉自由度高，但超出请求且会触碰稳定业务链路。
3. 在 renderer 壳层与日报生成主流程上做表现层 Feature：保留现有事件和数据边界，新增舞台感、指针光场、阶段反馈与响应式规则。

## 决策

采用路径 3。把改动收敛为一个 renderer 模块，新增单一 atelier 覆盖层样式与少量壳层交互；不引入新依赖，不改 IPC/数据库。

## 验收标准

- 页面在首次加载、深浅色、窄屏和 reduced-motion 下都保持可用。
- 主导航、主题切换、保存、生成、复制、导出、发布等既有操作仍可触发。
- 视觉上形成明确的“范围 → 生成 → 发布”三段叙事，首屏不再是均匀卡片堆叠。
- 所有新/改动的图标来自 `lucide-vue-next`，源码与可见文案无 emoji。
- 指针光场和卡片 hover 为增强层，不阻塞键盘与触控；状态变化有可读反馈。
